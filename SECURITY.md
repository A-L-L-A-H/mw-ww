# Security Policy

## Supported Versions

Only the latest release on the default branch receives security updates.

| Version | Supported |
|---------|-----------|
| Latest  | ✅        |
| Older   | ❌        |

## Reporting a Vulnerability

Do **not** open a public issue for security vulnerabilities.

Email the maintainers at **security@moonwitness.example** (replace with actual contact) with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fix

We aim to acknowledge within 48 hours and provide a fix timeline within 7 days.

## Disclosure

Coordinated disclosure is appreciated. We will credit reporters who follow this process.
